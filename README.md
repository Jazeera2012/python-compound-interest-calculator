# 💰 Compound Interest Calculator

A simple and interactive **Python Compound Interest Calculator** that calculates the final balance and keeps track of calculations made during the current session. 🐍

## ✨ Features

* 💵 Enter your own currency symbol
* 💰 Calculate compound interest
* 📊 Display the initial principal and final balance
* 🛡️ Validate user input
* ❌ Prevent negative values
* 🔄 Calculate again without restarting the program
* 📜 Keep a history of calculations during the current session
* ⚠️ Handle invalid input with helpful error messages

## 🧮 How It Works

The calculator uses the compound interest formula:

**Final Balance = Principal × (1 + Rate / 100)ᵀⁱᵐᵉ**

For example:

```text
Currency: $
Principal: 1000
Interest Rate: 5%
Time: 10 years

Final Balance: $1,628.89
```
